Project discription 

The municipal financial management system(MFMS) is a C based system which was developed to manage basic municipal financial information'.
The system provides a foundaation for manging municipal employees, budgets, suppliers, qssets and reports. It demonstrates the use of programming concepts including variables, data types, input validation, decision making, loops, arrays, strings and functions.

System Features:
* Employee Management
* Budget Management
* Supplier Management
* Asset Management 
* Reports
* Searching
* Input validation

  Compilation Instructions:
  The system can be compiled using GCC.
  gcc main.c assets/assets.c employees/employees.c budget/budget.c suppliers/suppliers.c reports/reports.c -o MFMS

  How to run the system
  Afeter successfully compiling the program, run the system using : ./MFMS
  On windows, the executable can be run using:
  MFMS.exe

  The system will then display the Municipal Financial Management System main menu, for which the user can select the  required management module.
